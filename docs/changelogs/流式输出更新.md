## 🔧 技术细节

### 流式处理函数
```python
def stream_qwen_response(response_stream):
    """千问流式响应"""
    for chunk in response_stream:
        if chunk.choices[0].delta.content:
            yield chunk.choices[0].delta.content

def stream_gemini_response(response_stream):
    """Gemini流式响应"""
    for chunk in response_stream:
        yield chunk.text
```
