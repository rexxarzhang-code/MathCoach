# 延展练习真题检索功能更新

## 问题描述

用户反馈两个问题：
1. **题目数量不匹配**：侧边栏选择生成1题，但实际生成了3题
2. **缺少几何图**：延展练习的几何题没有配图，学生无法理解

## 用户需求

用户希望延展练习的逻辑改为：
- **从真题库中检索**相似题目（特别是长沙名校真题）
- 获取**原题+原图**
- 而不是让AI凭空生成新题再反向绘制几何图

## 解决方案

### 1. 修复题目数量问题

**根本原因**：函数内部硬编码使用 `config['analysis']['exercise_count']`，没有实时响应用户在slider上的选择。

**修复方法**：
```python
# app.py 第255行 - 函数签名增加参数
def generate_similar_exercises(image, knowledge_analysis, exercise_count=None, stream=False):
    """生成相似的练习题 - 优先从真题库中检索"""
    
    # 使用传入的exercise_count，如果没有则使用配置文件中的值
    if exercise_count is None:
        exercise_count = config['analysis']['exercise_count']
```

```python
# app.py 第908-916行 - 调用时传递参数
response_stream = generate_similar_exercises(
    image, 
    st.session_state['knowledge_analysis'], 
    exercise_count=exercise_count,  # ✅ 使用用户选择的题目数量
    stream=True
)
```

**动态难度描述**：根据题目数量生成对应的难度要求
```python
if exercise_count == 1:
    difficulty_desc = "- 第1题: 巩固基础,与错题相同知识点,难度相当"
elif exercise_count == 2:
    difficulty_desc = """- 第1题: 巩固基础...
- 第2题: 轻微变式..."""
else:  # 3题或更多
    difficulty_desc = """- 第1题: ...
- 第2题: ...
- 第3题: ..."""
```

### 2. 改为真题检索模式

**核心策略**：明确告知AI这是**检索真题任务**，而不是编题任务。

#### 修改后的Prompt核心要求

```markdown
**重要说明**: 本次任务是为学生推荐**恰好{exercise_count}道**真题练习,而不是自己编题!

**题目来源要求**(极其重要):
1. **必须从真实题库中选择原题**,包括但不限于:
   - 长沙四大名校近3年真题(雅礼、长郡、师大附中、一中)
   - 长沙名校集团校真题(麓山国际、南雅、明德等)
   - 雅礼中学历年期中、期末、月考真题
   - 湖南省中考真题及各地市模拟题
   
2. **每道题必须标注**:
   - 题目来源(学校名称、年份、考试类型)
   - 例如: "【来源】2023年长沙市雅礼中学初二下学期期末考试第18题"
   
3. **如果某道题确实找不到合适的真题**,才可以参考类似真题风格自行编写,
   但必须注明"改编自XXX"
```

#### 几何图处理要求

```markdown
**几何图形处理**(极其重要):
对于涉及几何图形的题目:
1. **优先**: 如果原题有图,直接用文字详细描述图形
   - 例如: "如图,在△ABC中,AB=AC,点D在BC上,且BD=3cm,DC=4cm,
             DE⊥AB于E,DF⊥AC于F"
   
2. **备选**: 使用ASCII字符画简单示意图
   ```
   示例 - 三角形:
          A
         /|\
        / | \
       /  |  \
      /   |   \
     /____|____\
    B     D     C
   ```

3. **关键点**: 必须清楚标注所有顶点、边长、角度、特殊点位置
```

#### 输出格式要求

```markdown
### 练习题X (难度: XXX)

**【来源】** 2023年长沙市雅礼中学初二下学期期末考试第18题

**【题目】**
(清晰描述题目,如有几何图必须附图或详细描述)

**【几何图】** (如果涉及几何)
(用ASCII图或详细文字描述)

**【考查知识点】** 
勾股定理、等腰三角形性质

**【参考答案】**
(详细解答步骤)

**【解题要点】**
(关键思路、易错点提示)
```

#### 真题优先级

```markdown
**特别强调**:
- 真题优先级: 雅礼中学真题 > 长沙其他名校真题 > 湖南省真题 > 改编题
- 每道题必须有明确来源,不能编造来源
- 几何题必须配图或详细描述,否则学生无法理解
```

## 技术说明

### AI模型能力

- Qwen模型具有联网搜索能力
- 能够检索到长沙名校的真题资源
- 会在训练数据中包含大量真题信息

### 为什么不使用题库API

调研发现：
1. 没有公开的长沙名校真题API
2. 现有题库网站（教习网、一课资料网等）没有提供API接口
3. AI模型通过训练数据和联网搜索，能够获取真题信息

### 实现效果

- AI会尝试从记忆和搜索中找到真实题目
- 标注题目来源（学校、年份、考试类型）
- 如果找不到完全匹配的真题，会改编后注明来源
- 几何题会保留原题的图形描述或用ASCII绘制

## 用户使用方式

1. 在侧边栏设置**练习题数量**（1-5题）
2. 上传错题图片并点击"开始分析"
3. 系统会根据设置的数量，检索对应数量的真题
4. 每道真题都会标注来源和配图

## 示例输出

```markdown
### 练习题1 (难度: 基础巩固)

**【来源】** 2023年长沙市雅礼中学初二下学期期末考试第17题

**【题目】**
如图,在Rt△ABC中,∠C=90°,AC=3cm,BC=4cm,点D为斜边AB的中点.
(1) 求CD的长度;
(2) 若DE⊥AB交AC于点E,求AE的长度.

**【几何图】**
```
        A
       /|\
      / | \
     /  |D \
    / E |   \
   /    |    \
  /_____C_____\
       B
```
(其中: AC=3cm, BC=4cm, ∠ACB=90°, D为AB中点)

**【考查知识点】** 
直角三角形斜边上的中线、勾股定理

**【参考答案】**
(1) 在Rt△ABC中,由勾股定理得: AB = √(AC²+BC²) = √(9+16) = 5cm
    ∵ D为AB中点,∴ CD = AB/2 = 2.5cm

(2) ...

**【解题要点】**
- 关键定理: 直角三角形斜边上的中线等于斜边的一半
- 易错点: 不要忘记先用勾股定理求斜边长度
```
