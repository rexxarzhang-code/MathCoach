## 📝 Prompt增强

### 所有AI分析都会包含目标学校信息

#### 1. 知识点分析 (`analyze_knowledge_points`)

新增内容：
```
学生信息:
- 地区: 长沙市
- 年级: 初中二年级
- 教材: 人教版
- **学习目标**: 考上长沙四大五小,目标高中是**雅礼中学**
```

增强分析维度：
- **对于目标雅礼中学的重要程度**: 必考/常考/偶考
- **对于雅礼中学录取标准的掌握要求**: 基础必会/重点掌握/拔高训练
- **雅礼中学近年自主招生/选拔考试中的考察频率**
- **备考建议**: 针对目标雅礼中学,此知识点的重要性和建议训练强度

#### 2. 错因诊断 (`diagnose_error`)

新增内容：
```
学生背景:
- 目标: 考上长沙四大五小,目标高中是**雅礼中学**
- 当前年级: 初中二年级
```

增强分析维度：
- **针对目标雅礼中学**: 此类错误如果不改正,对考入雅礼中学的影响程度(严重/中等/轻微)
- 建议的训练重点和强度
- **激励与目标**: 以目标雅礼中学为动力,给予鼓励和具体的提升路径

#### 3. 延展练习 (`generate_similar_exercises`)

新增内容：
```
**学生当前学习阶段**:
- 年级: 初中二年级
- 学期: 上学期
- 已学范围: 三角形、全等三角形、轴对称、整式乘除、因式分解
- **严禁使用**: 圆、相似三角形、锐角三角函数、二次函数、向量、解析几何
- **学习目标**: 考上长沙四大五小,目标高中是**雅礼中学**
```

增强约束：
- **重点参考雅礼中学近年考试真题的出题风格和难度**
- **特别模拟雅礼中学的出题风格和难度梯度**

难度调整：
- 第2题: 稍难 - 轻微变式,增加一个条件或步骤,**达到雅礼中学中等题水平**
- 第3题: 综合应用(不超纲) - 知识点融合,但不得超出初中二年级教学大纲,**模拟雅礼中学选拔题难度**

## 🔍 实际效果示例

### AI分析示例（知识点分析）

**原来**：
```markdown
## 核心知识点
本题考查全等三角形的判定...

## 难度等级
对于初中二年级学生：中等难度
```

**现在**：
```markdown
## 核心知识点
本题考查全等三角形的判定...

## 对于目标雅礼中学的重要程度
⭐⭐⭐⭐⭐ 必考知识点
全等三角形是雅礼中学每年必考内容，通常出现在：
- 期中考试第18-20题（几何证明题）
- 期末考试压轴题的基础部分
- 自主招生考试中作为综合题的子问题

## 掌握要求
对于雅礼中学录取标准：**重点掌握**
- 基础判定方法（SSS/SAS/ASA/AAS/HL）必须100%准确
- 辅助线构造全等需熟练掌握
- 建议训练强度：每周至少完成5道相关综合题

## 备考建议
针对目标雅礼中学：
1. 此知识点重要性：⭐⭐⭐⭐⭐（满分）
2. 建议训练强度：高强度训练
3. 推荐资源：
   - 雅礼中学近3年期中/期末真题
   - 长沙四大名校联考几何专题
   - 人教版配套《培优练习》P45-P60
```

### AI诊断示例（错因诊断）

**原来**：
```markdown
## 错误分析
学生在证明全等时，遗漏了关键条件...

## 改进建议
建议多练习全等三角形的判定...
```

**现在**：
```markdown
## 错误分析
学生在证明全等时，遗漏了关键条件...

## 对考入雅礼中学的影响
⚠️ **影响程度：严重**

这类错误如果不改正，将直接影响考入雅礼中学：
- 雅礼中学几何证明题占分：15-18分（满分120分）
- 此类错误会导致该部分失分5-8分
- 预估影响总分排名：下降50-80名
- **风险**：可能无法达到雅礼中学录取线（通常需要110分以上）

## 训练建议
针对雅礼中学备考：
1. **训练重点**：全等三角形证明完整性
2. **训练强度**：每天至少2道证明题，持续1个月
3. **练习资源**：
   - 雅礼中学历年真题第18-20题
   - 长郡、雅礼、麓山联考几何专题
4. **检查方法**：建立"证明步骤检查清单"

## 激励与目标
加油！雅礼中学就在前方！🎯

改正这个错误，你离雅礼中学又近了一步！
全等三角形是雅礼中学必考内容，掌握好它，
你就拥有了冲刺雅礼的重要武器！

**行动计划**：
- 本周目标：完成20道全等证明题，正确率95%以上
- 本月目标：攻克雅礼近3年几何真题
- 期末目标：几何证明题稳定在14分以上（满分15分）

相信自己，雅礼中学在向你招手！💪
```

## 🎁 使用建议

### 给家长的建议

1. **首次使用时配置目标**
   - 在侧边栏设置孩子的目标高中
   - 设置学校群体（如四大名校、四大五小）
   - 点击"💾 保存配置"

2. **查看AI建议**
   - AI会根据目标学校调整分析重点
   - 关注"对考入XX学校的影响"部分
   - 参考建议的训练强度和资源

3. **制定学习计划**
   - 根据AI给出的重要性评级
   - 优先攻克高重要性知识点
   - 按照建议的训练强度执行

4. **定期调整目标**
   - 根据孩子学习情况
   - 可以修改目标学校
   - AI会自动调整建议策略

### 给孩子的建议

1. **明确目标**
   - 每次分析都会看到目标学校
   - 提醒自己为什么要努力

2. **关注重点**
   - 看AI标注的"对考入XX的影响"
   - 优先解决"严重影响"的问题

3. **执行计划**
   - 按照AI建议的训练计划
   - 每天检查进度
   - 相信坚持的力量
