# PDF导出功能说明

## 🎉 新增功能

已为错题分析报告添加**PDF导出功能**，支持A4尺寸打印，方便为孩子打印学习材料。

## ✨ 功能特点

### 1. A4标准尺寸
- 页面尺寸：A4（210mm × 297mm）
- 页边距：2cm（上下左右）
- 适合直接打印，无需调整

### 2. 专业排版
- **标题层次分明**
  - 一级标题：20pt，居中，蓝色底线
  - 二级标题：16pt，左对齐，蓝色左边框
  - 三级标题：14pt，加粗
  
- **正文易读**
  - 字体大小：11pt
  - 行间距：1.6倍
  - 两端对齐

- **数学公式标记**
  - LaTeX公式以斜体形式显示
  - 清晰标注公式内容
  - 例：$ax^2 + bx + c$ 显示为 *ax² + bx + c*

### 3. 中文字体支持
自动检测并使用macOS系统中文字体：
- 优先使用：华文黑体（STHeiti Light）
- 备选：苹方（PingFang）、宋体（Songti）
- 保证中文显示效果

### 4. 双格式下载
在"📄 完整报告"标签页提供两个下载选项：

| 格式 | 用途 | 按钮 |
|------|------|------|
| **Markdown** | 数字化存档、编辑 | 📥 下载Markdown报告 |
| **PDF** | 打印、阅读 | 📑 下载PDF报告（A4打印）⭐ |

## 📖 使用方法

### 步骤1：分析错题
1. 上传错题图片
2. 等待AI分析完成

### 步骤2：查看报告
切换到"📄 完整报告"标签页

### 步骤3：下载PDF
1. 点击"📑 下载PDF报告（A4打印）"按钮
2. 系统会自动生成PDF（显示"正在生成PDF..."）
3. 下载完成后，文件名格式：`错题分析_[原文件名].pdf`

### 步骤4：打印
- 直接使用系统打印功能
- 无需调整页面设置
- A4纸打印即可

## 🔧 技术实现

### 核心库
- **reportlab**: PDF生成库
  - 轻量级，无系统依赖
  - 支持中文字体
  - 精确控制排版

### 关键特性
1. **自动Markdown解析**
   - 识别标题层级（#, ##, ###）
   - 处理列表项（-, *, 数字列表）
   - 保留粗体格式（**文本**）

2. **LaTeX公式处理**
   - 识别行内公式：`$公式$`
   - 识别块级公式：`$$公式$$`
   - 转换为可读文本格式

3. **Emoji过滤**
   - 自动移除emoji符号（如📚🔍💪）
   - 避免PDF显示异常
   - 保持专业文档风格

## 📊 对比优势

### Markdown vs PDF

| 特性 | Markdown | PDF |
|------|----------|-----|
| 打印质量 | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| 可编辑性 | ⭐⭐⭐⭐⭐ | ⭐ |
| 数学公式 | 需软件支持 | 直接显示 |
| 格式稳定 | 取决于阅读器 | 完全一致 |
| 适合打印 | ❌ | ✅ |
| 数字存档 | ✅ | ✅ |

### 推荐使用场景

**选择PDF：**
- ✅ 需要打印给孩子练习
- ✅ 需要标注和手写解答
- ✅ 分享给老师或家长
- ✅ 长期保存纸质版

**选择Markdown：**
- ✅ 需要二次编辑
- ✅ 数字化管理错题库
- ✅ 在支持Markdown的平台查看

## 🚀 性能说明

- **生成速度**：通常2-5秒
- **文件大小**：约50-200KB
- **兼容性**：所有PDF阅读器

## ⚠️ 注意事项

1. **数学公式显示**
   - PDF中公式以文本形式显示
   - 保持可读性，但不如网页渲染精美
   - 适合打印后手写补充公式

2. **字体兼容性**
   - macOS：自动使用系统中文字体
   - Windows/Linux：可能需要调整字体配置

3. **大文件处理**
   - 超长报告可能需要更多时间
   - 建议单次分析不超过10道题
